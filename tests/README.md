# 金额流程回归测试

覆盖报价单金额从输入校验、SQLite 持久化到 HTML 预览的完整流程。

## 运行

从项目根目录执行：

```sh
python3 -m unittest discover -s tests
```

- 仅依赖 Python 3 标准库，无需安装任何包。
- 全部通过时退出码为 0；任一断言失败时退出码非零，输出会指明
  失败样例（subTest 名称）与未满足的预期。
- 连续运行结果一致；测试在独立临时目录中读写数据库、JSON 与
  HTML，结束后自动清理，不触碰已有业务数据，也不在项目目录
  留下数据库或 HTML 文件。

## 覆盖内容

- **正常流程**：`save` 与 `preview` 以独立子进程执行公开命令。
  编号 `Q-AMOUNT-001`、客户“演示客户”，三行明细（咨询 2×1250、
  资料 1×300、赠品 4×0，单位分）。核对 stdout、SQLite 中的整数
  数量/单价/行金额（2500、300、0）与合计（2800），以及 HTML 中
  的明细顺序、数量、单价（12.50、3.00、0.00）、行金额
  （25.00、3.00、0.00）与总计（28.00）。
- **合法上界**：数量 1、单价 9223372036854775807 分，保存不丢
  精度，预览金额恰为 92233720368547758.07。
- **拒绝行为**：数量为零、单价为负、数量/单价为布尔值或浮点数、
  数量/单价超过 INT64 上界、单行乘积超界（2×4611686018427387904）、
  各行合法但合计超界（两行 1×4611686018427387904）。每个无效
  输入要求退出码 1、stdout 为空、stderr 以“错误:”开头并说明
  对应问题；数据库原本不存在时不得被创建，已存在时已有记录
  保持不变且不残留本次报价或明细。
